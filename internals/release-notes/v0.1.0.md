MVS/CE 0.1.0 is MVS 3.8j as Jay Moseley's installation procedure builds it, with every step automated and checked. It is the plain system from his guide, ready to IPL under Hercules: no extra software yet, and only three small changes to his files, listed below.

## Read this first

- **This is Jay Moseley's system, not more.** It has what his guide installs: the generated MVS 3.8j with his PTFs and usermods, JES2, VTAM and TSO, RPF, QUEUE, REVIEW and DATE, and his SYSCPK volume of compilers and tools. Security software and other additions come in later releases.
- **Hercules:** the package was built and booted with SDL Hyperion 4.10.0.11799 (develop 7607b082) on Linux amd64, and booted on macOS arm64. It has not been tried on Linux arm64 yet. Other SDL Hyperion 4.x versions will probably run it, untested. Building it needs a Hercules with the fix of Hyperion PR #907 (see below); the build uses 7607b082, which has it.
- **Users:** HMVS01 and HMVS02 log on to TSO without a password, as Jay creates them.

## Building it by hand compared with this release

| | by hand, following the guide | 0.1.0 |
|---|---|---|
| Effort | about two hours by Jay's own estimates: some 30 jobs, many operator replies and tape mounts | one command, about 12 minutes on a laptop |
| Checking | reading condition codes in the printer output | every job's codes, job and step counts checked automatically; SMP inventory checked against what the jobs apply |
| Usermods | one jobstream | the same jobstream, unchanged |
| Inputs | whatever the download link serves that day | pinned by SHA-256 |
| Printer output of the starter system | Hercules before 7607b082 could drop blocks of 24 lines (a PCI interruption raised twice) | built with a Hercules that has the fix |

## Changes to Jay Moseley's files

| Change | Why |
|---|---|
| Starter configurations: console 01F as integrated 3215-C instead of a telnet 3215 | so the build can drive the console |
| `mvs.cnf`: Jay's commented-out integrated 3215-C at 009 enabled | the same for the new system; 009 is generated by Jay as a 3215 console |
| JES2 `&CKPTIME` 60 → 10 seconds | JES2 waits for its checkpoint timer to end; a shutdown takes 15 s instead of 65 |

## Install

```sh
sha256sum -c mvsce-0.1.0.tar.sha256
tar xf mvsce-0.1.0.tar
cd mvsce-0.1.0
./start_mvs.sh
```

Then, at the Hercules prompt, `ipl 150`, and answer as `README.md` in the package describes (Enter, `u`, `noreq`), and `s net` for TSO. Connect a 3270 client to localhost port 3270.

`MANIFEST.json` lists the inputs with their checksums, the Hercules version, the patches, the SMP inventory summary and the SHA-256 of every file; `smp-inventory.txt` lists every SYSMOD.
